# PyQt5 (Python Desktop Graphical User Interface Library)
# Installation
- `pip install pyqt5`
- `pip install pygame`

# Imports
- **sys** - This module provides access to some variables used or maintained by the interpreter and to functions that inter-act strongly with the interpreter. 
- **requests** - This module helps to fetch data from apis.
- **pygame** - This module helps to create 2D applications. It includes music, video, file, keyboard input... handling utility functions
